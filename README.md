# AE Guspira — web estàtica
Obre index.html directament o amb Live Server de VS Code. No cal PHP, Node ni Composer.

- assets/components.js: capçalera i peu compartits.
- assets/style.css: disseny original.
- assets/data.js: activitats del calendari. Exemple: `{title: "Cau", start: "2026-12-05", type: "cau", unit: "totes"}`.
- Cada pàgina HTML conté el seu contingut; les notícies i documents es poden editar a noticies.html i documents.html (i actualitzar l’inici si escau).
- Instagram, mapa i formulari extern requereixen internet. El contacte obre el client de correu.
- El projecte original no contenia activitats, notícies, publicacions ni documents carregats. Valideu textos, enllaços i permisos d’imatge abans de publicar.
